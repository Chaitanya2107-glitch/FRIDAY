# Behavioral life state: brain/life roadmap phase 2

Authorized by the owner asking to continue the saved roadmap on 2026-10-20.

## Behavior

Derive a shared local behavior state from canonical attention, responsibilities,
temporal uncertainty, explicit conversation preferences and actual interruption
feedback. Separate permission to review silently from permission to interrupt.
Typing, gaming, calls, active requests and unavailable attention inhibit expensive
review; away/quiet preferences can still allow silent review. Quiet preferences,
busy activity, imminent timed commitments and learned cooldown inhibit optional
conversation. Essential warnings and requested reminders retain existing contracts.

Supply this state to existing local executive, inquiry and notification review.
The model still chooses meaningful questions/proposals or silence. State labels
are software priorities, never evidence of completed tasks or authority to act.
Current and upcoming commitments suggest support; blockers/unknown dates suggest
investigation. No new model loop, question quota or automatic plan execution.

## Timing adaptation

Retain bounded, source-deduplicated reaction receipts in cognition SQLite. Context
is activity category, mode and broad time of day as recorded when the interruption
was prepared. Learn only from autonomous questions actually offered for delivery;
withheld/failed-before-delivery questions and explicit requested replies do not
train autonomous welcome. An unanswered offer is weak evidence of timing, never
proof of rejection. Repeated explicit declines in the same context lengthen a
bounded cooldown. Positive replies cannot override a hard quiet/pause/busy gate.
Use existing local persistence/forget/epoch boundaries; retain no raw answer text
in the timing ledger. Remote answers cannot consume laptop pending questions.

## Respectful persona and visibility

Remove negative warmth and sulking/abandonment claims after quiet requests or
absence. Describe quiet/restraint as respecting the owner's preferences. Expose
current posture, reasons, review/interruption gates, responsibility basis and
learned cooldown in local brain diagnostics/API and life reports. Do not attach
local behavioral context to remote conversation.

## Verification

Prove pure state decisions, relevant source selection, quiet versus silent review,
imminent timing, uncertainty, feedback persistence/deduplication, restart, forgetting,
explicit requests and unchanged global caps. Cover delayed/withheld delivery and
feedback after attention changes. Exercise actual executive/inquiry/notification
boundaries with deterministic providers; run focused/full regressions and a bounded
synthetic local inference probe. Save results and next continuation in the roadmap.
