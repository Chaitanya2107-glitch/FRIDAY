# Memory consolidation: first increment

Build local, extractive memory threads during the existing guarded executive review.
The model proposes only a short topic and two to four related original local episode
IDs. A separate local critique checks the relationship. Stored excerpts retain exact
owner wording, paired questions and original dates; the topic is an inferred label.
There is no generated factual recap, owner-fact insertion, tool execution or new loop.

Persist at most 100 threads with bounded original source snapshots. They survive the
500-episode rolling window, remain inspectable after restart, and feed local reasoning.
Never consolidate another summary or a remote message. Reject missing, altered,
duplicate or unrelated sources, and recheck within the executive's transaction/epoch.
An existing identical grouping is idempotent; a new overlapping grouping retires older
ones. Commitment corrections retire affected threads, keep per-commitment links to ALL corrected
original sources and require those sources when regrouping historical reports. Retain
original uncertainty and dates; elapsed time and an answered question prove no action.

When the model proposes temporal and memory work together, defer only the optional
grouping; independently validate/critique the temporal interpretation before saving.

Use existing five-minute/four-per-hour review budgets, attention deferral, local model,
generation/critique timeout and forget fences. Forgetting clears threads AND snapshots.
Expose active threads and provenance in local brain inspection/API; exclude private
summaries and their conclusions from remote prompts and mirrored suggestions.

Verify retention/restart, corrections and correction chains, exact snapshots, source
mutation/forget races, bounded storage, duplicate/recursive/remote rejection, actual
executive schema/generation/critique/save, local context and remote exclusion. Run a
bounded synthetic installed-model probe without real owner data or actions.

Limits: this is extractive historical continuity, not a general semantic identity or
contradiction solver. Uninterpreted arbitrary new corrections are new historical
reports until reviewed; a topic label is not a confirmed fact. Bounded retention may
eventually discard old threads. Silence or rejected grouping is a valid review result.

Storage also caps reachable provenance at 800 original snapshots. Evict complete oldest
threads when necessary, preserving all needed correction links for any retained thread.
