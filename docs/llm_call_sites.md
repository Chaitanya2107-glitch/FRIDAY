# FRIDAY model call sites before the offline changes

This inventory covers Python runtime paths and development probes. The baseline comes from source inspection, including the brain roadmap, foundations and October assessment. Timings describe existing limits, including additional local server startup where applicable.

| Entry point | Missing, slow or unusable model today | Rule fallback | Risk |
| --- | --- | --- | --- |
| `providers/failover.py`, `providers/registry.py`, `providers/base_provider.py` | Tries providers serially, with optional per-attempt limits. A partial voice stream can be returned as incomplete. | None at the transport layer. | Multiple waits. Direct factory use bypasses failover limits. |
| `providers/ollama/client.py`, `providers/ollama/runtime.py` | Checks `/api/version`, can start an owned server, and uses `/api/chat` with a 120-second request timeout. Readiness can use `/api/ps` and prompt-free `/api/generate`. | None. | Cold starts can consume a review budget. Readiness is itself model work. |
| `providers/openrouter/client.py`, `providers/openai/client.py`, `providers/anthropic/client.py` | Provider SDK completion and voice streaming can wait on network/SDK retries. OpenRouter may retry on other models. | Failover only. | Long tails, and different provider selection for pinned image consent. |
| `services/network/status.py:warm_local_model` | An offline transition directly posts to `/api/generate`, up to 60 seconds. Startup launches the watcher as a task. | Watcher logs failure. | Unwanted model contact on a network change and delayed connectivity recovery. |
| `interfaces/api/routes/chat.py:chat`, `interfaces/api/routes/voice.py:_handle_voice` (legacy non-assist mode) | Direct completion after local routing and memory context. Model failure can end the turn as an API error. Voice can stream partial output. | Literal local routing runs first. | Uncaught provider failures and unsupported request wording. |
| `services/mind/language.py:understand` | Structured paraphrase-to-command attempt, up to 22 seconds. Invalid or failed output yields no command. | Deterministic router, aliases and typo handling run first. | Nonliteral action requests can fall through to conversation. |
| `services/mind/language.py:answer`, `services/remote/conversation.py:answer` | Local conversation advertises unavailable AI after bounded attempts. Isolated remote conversation reports a provider error to its caller. | Local conversation handles some greetings, facts, references and selected work first. | Missing general conversation and potentially confusing phrasing for unknown requests. |
| `services/automation/intent.py:_classify_with_ai`, `_run_ai_tools` (legacy non-assist mode) | Calls providers directly for intent JSON with per-provider waits. Invalid output advances to another provider or abstains. | Local intent, shortcuts and authored routines. | Direct factory bypass, with authority depending on the legacy mode and downstream guards. |
| `services/automation/writer.py:write` | Free-form writing request fails if no model supplies text. | Owner can issue a literal `type` command. | Generated text may be mistaken for text the owner approved. |
| `services/automation/personality.py:roast_me`, `services/mind/wording.py:say/enhance` | Optional phrasing can wait on providers. Invalid wording is rejected by local checks. | `wording.plain`, original sentence and local roast. | Wording should never change names, facts, negations or outcomes. |
| `services/mind/knowledge.py:look_up` | Invalid/unavailable result is recorded as a lookup without a usable description. | Known app/category rules and one owner question. | Incorrect model explanations require owner approval before entering knowledge. |
| `services/mind/reasoning.py:analyze/_critique`, `review_metrics.py:complete` | Executive and dialogue reviews can warm the model, generate, retry and independently critique. Failed reviews defer via existing lease/backoff. | Local evidence validation and date anchoring after generation, existing executive safety gates. | Clear owner date reports still depend on a model pass. Reviewed interpretations can be saved without a separate owner confirmation. |
| `services/mind/inquiry.py:think` | The bounded local request can fail, returning no usable inquiry decision. | Existing context and gap ranking, plus direct owner commands. | A source-backed question can be lost along with model-generated wording. |
| `services/mind/recall_review.py:supports` | Missing, late or invalid semantic relation check abstains. | Literal evidence selection and saved topic references. | Some paraphrased recall requires the owner to supply the original name or wording. |
| `services/mind/notifications.py:_reason` | Bounded optional review fails back to local decisions. | Rule decisions, quiet/busy context, budgets and urgent/requested delivery rules. | Inline batch review can postpone delivery while inference runs. |
| `services/mind/reminder_review.py:review` | Failed/invalid review retains the reminder and records unavailability. | Existing explicit and local rules. | A review timeout can hold up processing of later reminders in the same scheduler pass. |
| `services/mind/reflection.py:reflect`, `services/memory/episodes.py:summarize_if_due` | Failed generation skips the profile or episode summary. These paths are inactive in assist-only mode. | Original owner messages and local learning. | A failed episode write is skipped after the cursor advances. Legacy summaries are generated text. |
| `services/memory/semantic.py:_learn/_replaced` | Legacy fact extraction and replacement checks skip failed/invalid results. | Explicit notes and owner-provided learning. | Legacy generated facts can enter memory if assist-only is disabled. |
| `services/activity/git_status.py` commit drafting | Calls Ollama directly after obtaining staged-change statistics. | Assist-only mode already formats a local draft. | Missing model in legacy mode prevents draft creation. |
| `services/browser/service.py:_plan`, `services/computer/agent.py:_propose` | Bounded planning from browser state or the latest desktop screenshot. Failed output halts work. | Manually authored commands, existing approval/step checks and cancellation. | Invented actions must stay proposals. Model-free arbitrary visual automation has no safe inferred substitute. |
| `services/browser/research.py:queries_for/synthesize` | Query planning, cited synthesis and independent claim check each have a bound and can abstain. | Original topic search and source-only results. | Generated claims need review even with exact quotes. |
| `services/vision/screen.py` explicit image question | Vision completion skips incompatible Ollama models and may fall back to another provider. | Direct screen/app metadata commands. | Screenshot privacy and a plausible but wrong visual answer. |
| `services/screen_watch/inference.py:local_chat`, `companion.py` | Direct local `/api/tags`, `/api/show` and `/api/chat`, with up to 55 seconds. Guards can refuse context before and after submission. | Separate observed app/window context and local privacy gates. | Direct transport ignores the rest of model policy and error budgets. Model interpretations must stay provisional. |
| `services/proactive/timetable_extract.py:extract_classes`, `services/college/uploads.py` | Vision extraction uses failover or pins the exact approved provider/model via a direct call capped at 90 seconds. | Manual classes and existing schedule data. | A guessed timetable can create bad alerts. Apply remains owner-confirmed. |
| `services/files/embed.py`, `services/files/index.py`, `services/memory/semantic.py`, `services/mind/recall.py` | Sentence-transformer load/encode can be slow or fail. Recall uses installed weights only and a caller deadline. | Filename search, explicit notes and literal recall. | Shared embedding locks and unbounded model loads can occupy workers. Stored vectors must retain their original meaning. |
| `plugins/semantic_search/embedding.py`, `indexer.py`, `query.py`, `main.py` | FastEmbed or SentenceTransformer load/encode can fail or block an indexing/search worker. Download is explicit. | Existing lexical results when vectors are unavailable. | Index availability and cancellation. |

Speech recognition, voice activity detection and speech synthesis are separate signal-processing/voice components. They parse or render audio and do not provide FRIDAY with language-model conclusions or action authority. Existing `faster_whisper` recognition, Edge/Piper/system voices and OCR keep their independent settings and fallbacks.

Development probes using the public failover path inherit its existing limitations. `tasks/probe_inquiry_latency.py` has an additional direct `/api/chat` benchmark. `tasks/prepare_screen_vision.py` uses `/api/version`, `/api/tags`, `/api/show` and explicit `/api/pull` provisioning. `tasks/probe_review_reliability.py` reads `/api/ps`; other `tasks/probe_*` modules use the runtime for readiness, cleanup or controlled lifecycle measurement. Those tools are operator-invoked. Production startup does not invoke them.
