# Native Android companion and additive receiver

User authorized local code, tests, SDK build and a debug APK; no release, commit, production restart or live owner-data mutation. Codex is sole writer, with read-only source/API review agents. Existing uncommitted P1 changes are preserved. No tracked collaboration lease harness is installed. Ruflo remains a coordination/policy ledger, not the runtime authorization authority.

Receiver: services/phone_signals, memory/phone/phone_events.db; no edits in KDE Connect services/phone. Explicit phone_data scope requested at pairing and approved on laptop; no grants to existing records. Existing P0 safe/confirm risks, signatures, gate, kill switch, revocation and origin propagation remain authoritative. Strict per-type finite fields, <=50 events, <=2048 bytes per event, existing 16KiB request cap, composite device/id dedupe, 30-day retention. phone.event publishes only type/time plus mandatory remote-origin provenance. Forget removes event/heartbeat data and increments an opaque tombstone generation to reject stale uploads.

Android: min29, target37, current verified stable AGP9.5.1/Gradle9.6.0/Kotlin2.4.21, Compose, Room, OkHttp. SDK37 and Studio JBR25 exist here. All signals opt-in, explanations before dangerous/special permission requests, no startup permission prompts. Room first, seven days/5000 rows maximum, durable acknowledged receipts, five-minute foreground batches and15-minute WorkManager fallback. No automatic command queue. Health aggregates and explicit named geofences only; raw coordinates stay in private local configuration. No GPS samples, contacts, content capture, accessibility, calls/SMS, mic or photos.

Notification wire contract remains metadata-only even if a local per-app content preference is recorded: receiver rejects title/text/content fields. Media title/artist are a distinct opt-in media-session schema. No notification extras are read. MLKit bundled barcode scanning has telemetry; restrict app TLS trust to ts.net and client requests to the exact QR origin, remove automatic initialization, keep no analytics SDK or external login.

Validation: strict Python schema/scope/gate/retention/dedupe/forget fencing tests, all existing Python tests; pure-JVM canonical/signature vectors, toggle/buffer/sender tests with fake server; actual Room test under Robolectric; build debug APK if installed SDK and network dependencies allow. Do not claim physical sensors, OEM background reliability or health/geofence behavior without device evidence. Bind final receipts to exact source hashes and disclose build/test limitations.
