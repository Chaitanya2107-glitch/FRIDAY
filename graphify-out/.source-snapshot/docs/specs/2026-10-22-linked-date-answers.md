# Short answers to date clarifications

Retain the existing inquiry ID alongside the original question, answer and
receipt date for replies to an offered local question. Reuse the inquiry's
recorded evidence fingerprints, gap version and epoch to bind only one current
undated commitment. Do not infer the target from a similar question or subject.
Missing, changed, remote, expired/cleared or multiple-target provenance cannot
establish a date-answer link. Keep the optional reference in the owner episode
so existing retention and forgetting remove it with that episode.

Prioritize an unambiguous whole date answer with a verified link using the
existing pending-correction path. Anchor it to its original receipt time, not
review time. Existing generation, independent critique, source validation and
transactional persistence remain mandatory; no new calls, retries or budgets.
Validate the inquiry and target again inside the save transaction. A short date
fragment without a valid link must not revise an existing commitment through a
different model-selected path. Ambiguous/uncertain replies leave the current
commitment unresolved. A named self-contained rescheduling report keeps its
existing path.

Preserve history and the original question after restart. Already accepted
revisions remain idempotent. Legacy episodes without a link are not backfilled.
No automatic question, action or canonical reminder/deadline update is added.

Verify actual talk-answer wiring, stale questions/versions, unrelated and
ambiguous replies, remote/unoffered answers, malformed output, source/inquiry
changes during inference, forgetting, restart and calendar anchoring. Evaluate
the existing local model with frozen synthetic fixtures and retain failed trials.
