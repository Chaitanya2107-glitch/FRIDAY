# Tkinter control center

The owner requested one native UI covering FRIDAY's abilities, setup, usage and
example commands. Reuse the existing backend and editors, with no new dependency.

Acceptance: a resizable dark Tkinter desktop with overview, searchable capability
and command catalog, real chat and confirmation flow, offline local guides,
runtime status, and native editor/desktop controls. Examples prepare drafts; only
Send executes. Preserve failed drafts, surface unavailable services, keep HTTP and
desktop operations off the Tk thread, and never save private replies in this UI.
Typing requires an explicit target handoff and a fresh foreground-window check.
The app never starts the backend or microphone merely to browse documentation.

Catalog: the production PHRASE_GROUPS registry plus current browser, phone,
screen-awareness, habit/task, college and cognition commands. Show descriptions,
usage, requirements and local documentation without claiming all integrations
are connected. Existing commands retain their own approvals and permissions.

Policy decision receipt: allow the user-requested reversible local implementation,
tests and documentation. Root is the sole writer; capability_map and
ui_integration are read-only researchers sharing this checkout. No tracked
collaboration harness/action capability adapter is installed. Ruflo tools are
unregistered and CLI discovery found no installed cached package; proceed with
repository instructions and local evidence. No dependency install, commit,
publish, external message, owner-data mutation or backend restart is part of
development verification. Tk checks require desktop permission because the
sandbox cannot load Tcl. Use fake clients and existing isolated test fixtures.

Validation: catalog coverage, search, example staging, request shapes, error and
confirmation handling, target checks, real Tk navigation/resizing/responsiveness,
safe shutdown, tray entry and focused API/security regressions. Record source
hashes and final results in tasks/control-center/receipt.json.
