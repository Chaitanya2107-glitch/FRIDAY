# Brain foundations: health, working context and source-backed recall

The owner authorized starting the brain/life/memory/reasoning upgrades after a
read-only review. Implement the first priorities: cognition health and useful,
source-backed working memory. Keep later broad semantic understanding and
autonomous workflows separate from this increment.

Baseline: the live attention loop reports running, but the life gate reports a
call/microphone block. Retained executive attempts end on October 22 while
observations continue into November 5. Empty derived tables do not establish a
failure. Diagnose liveness, gates and persistence without changing preferences,
inference limits or authorizing actions. Source inspection also found that a
startup failure in evening.stop can leave an open-loop flag falsely reporting
the cognitive task alive.

Acceptance:

- Actual task liveness, startup failure, interruption and shutdown are factual.
- Local brain status explains current gate/budget reasons and latest progress.
- Bounded scalar review diagnostics survive observation-event retention and
  process restart. No source quotes, prompt content, model replies, credentials
  or arbitrary exception text enter the diagnostic store.
- Existing forget operations clear private derived diagnostics and fence late
  workers. Diagnostic failures cannot turn failed reasoning into success.
- Working memory reuses explicit selected tasks/commitments and original reports;
  current source versions, correction chains, expiry and privacy scopes govern
  retrieval. It cannot infer an action, task completion or permission.
- Preserve existing mismatch refusals and semantic recall checks; no relaxed
  similarity thresholds or model prompt experiments without measured evidence.
- Focused runtime, memory, privacy, forgetting and real chat/voice regression
  checks run in isolated test storage. Record exact source hashes and a bounded
  source-bound benchmark in tasks/brain-foundations.

tests and documentation. Root is the only writer. Existing researchers were
read-only; their optional turns stopped at the service usage limit, so root
continues implementation and validation. Local policy is legacy and no live
